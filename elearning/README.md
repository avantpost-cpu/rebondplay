# RebondPlay — E-learning

Prototype du nouvel espace e-learning RebondPlay.

## Tester

Après publication GitHub Pages, ouvrir : `https://rebondplay.com/elearning/`.

Le prototype comprend le parcours de sensibilisation, les quatre cartes de séquences et le déroulé vertical complet de la séquence 1. La jauge suit le défilement du premier chapitre. Les liens interactifs existants sont conservés.

## Ressources liées

- Fond papier et logo : réutilisés depuis la racine et `pagefull/`.
- Les vidéos Digiforma ne sont pas encore copiées dans ce dossier ; les emplacements médias sont à relier aux fichiers définitifs.
- Les séquences 2 à 4 sont des écrans de structure, à compléter avec leurs contenus.

Le texte de la séquence 1 provient du document fourni et est conservé dans la page.
